# PSC316 室外机规格书

本skill保存用户2026-11-09提供的外机规格，作为核对代码与测试预期的依据。当前实现、旧测试预期、旧Word说明均不能代替用户原文。

- 先读[条款及参数索引](references/spec-index.md)，按涉及条款读[用户原文](references/outdoor-spec-original-20261109.txt)。原文中的笔误和空图位置保留，解释另列。
- 涉及环境许可、−15～43℃双风机加载时，结合[流程图转录](references/flowcharts.md)与其链接原图；尤其检查严格大小于、运行/停机分支、保持计时的连续性。图中的“所有”“任一”“较小值”不可互换。
- 判定争议前读[未决点与解释边界](references/clarifications.md)。文字和图互相矛盾时，列出两种预期及实际行为，不以当前代码替用户定案；未指定的等号边界也不能悄悄当成已确认要求。
- 按[代码与接口定位](references/code-and-test-map.md)找入口。先绑定当前源码、构建产物哈希、版本及PRODUCTION/BENCH档。根据对应AXF解析符号，不复用旧RAM地址；保存源码清单匹配结果。
- 核对链路：330需求/禁用/化霜授权 → 316请求和实际输出 → 316故障/化霜状态 → 330镜像和跨机互斥。单函数通过不能证明完整扫描顺序、串口传输或多机交互通过。
- 逐条交付“规格要求—代码行为—证据—结论—下一步”。区分源码审阅、当前构建ARM离线执行、板上输入模拟、真实接线/端子测量；软件DA/DO反馈不是物理输出测量，BENCH缩时不证明正式秒数。保留失败和复测证据，不把框架运行成功计为验收通过。
- 化霜需覆盖正常/定时降级、逐压机退出、30秒补开、60秒恢复、互斥，以及运行中新增禁用/故障/急停；保护需分别验证出现、保持、解除、复位和另一健康系统继续运行。
- 规格是长期依据，测试状态和暂时缺陷写项目报告。本skill不扩大用户当次任务范围，也不自动授权烧录或启动暂停台架。内机PID、EEV、主/再/预热等按内机skill及用户后续确认另查。
