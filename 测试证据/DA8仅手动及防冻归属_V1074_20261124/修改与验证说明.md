# DA8仅手动调节及防冻归属修正

2026-11-24。330正式版V10.74，按用户最终要求DA8仅提供手动开度。用户确认DA0、DA1、DA9接电加热，DA8接冷热两用水盘管。

## 参数及使用

| 330地址 | 用途 | 范围及默认 |
| --- | --- | --- |
| 247 | DA8手动开度 | 0～1000对应0～100%，沿用原出厂默认500；已有保存设定沿用 |
| 346 | DA8冬季最小开度 | 0～1000对应0～100%，默认200 |
| 925 | DA8实际输出指令 | 0～1000 |
| 922 | 最终DA8输出指令 | 0～1000 |
| 245 | 旧模式地址兼容回读 | 固定手动1，旧值0不会重新启用自动 |
| 246 | 旧自动调节幅度 | 停用，对DA8输出无作用 |

制冷／制热运行状态下，DA8取247手动开度。新风严格低于0℃时，实际开度取手动值与346的较大者。恰好0℃不触发最小开度。手动设定保持原值，低温下限仅约束实际输出。正常停机、非制冷制热模式、传感器部分停机及故障／急停禁止时不因最小开度重新开启水阀。

本次沿用原手动开度默认500以及旧保存值。实际运行前应核对247，避免将原有保存开度误认为0。

## 修改范围

- 移除DA8温差分步自动调节及温度趋势辅助函数，开度按手动设置输出。
- DA0／DA1／DA9电加热AO及其需求不再强制应用水阀防冻最小开度。
- 冬季最小开度转到DA8。开启最小开度功能时，制冷／制热模式所需的新风NTC同时纳入传感器有效性检测。
- 普通手动输出适用于制冷与制热。原停止状态下不执行水阀手动输出的边界继续适用。
- 245保留兼容地址并固定为手动，247合法范围收窄到0～1000，默认500。

正常停机和急停优先于本次低温最小开度，未新增停机防冻保持。此处沿用项目原有输出优先级，规格原文未展开停机保持条件。

规格§3.11.10原文为“新风温度小于0度时蒸汽阀门/热水阀门开启度不得小于最小开度（可设）”。全文没有单列DA8普通自动算法。通道用途和仅手动调节依据本次用户确认。
