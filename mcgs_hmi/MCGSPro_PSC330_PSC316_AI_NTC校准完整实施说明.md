## 1. 开始前必须知道的事情

### 1.1 校准修改的是什么

当前校准采用单点偏移修正：

```text
新偏移 = 原偏移 + 标准内部值 - 当前内部值
```

例如：

```text
标准温度       = 25.0℃
PSC330当前显示 = 24.3℃
原偏移         = -0.2℃

内部值分别为：
标准值 = 250
当前值 = 243
原偏移 = -2

新偏移 = -2 + 250 - 243 = 5
```

最后向偏移寄存器写入`5`，表示`+0.5℃`。

这类校准只能修正整体偏移，不能修正斜率错误。AI在低、中、高三个点的误差如果明显不同，应先检查：

1. 传感器电气类型是否选错。
2. 量程上下限是否配置错误。
3. 0至10V和4至20mA接线是否正确。
4. 传感器、供电或采样电路是否异常。

不要用很大的偏移去掩盖输入类型或量程错误。

### 1.2 什么才能作为标准值

标准值必须来自独立的标准设备：

- 温度：经确认的标准温度计、恒温槽或温度校验仪。
- 湿度：标准湿度计或湿度发生器。
- 压差、风压：标准压力计或压力发生器。
- CO2：标准气体或经过校验的CO2仪表。
- PSC316冷媒压力：压力校验仪、标准压力表或压力发生器。

不能把PSC330或PSC316自己的显示值重新填进“标准值”，那样没有完成校准。

### 1.3 校准前必须停机

写入按钮要求：

```text
R0709_开关机步骤 = 0
```

也就是PSC330已经完全停机，不是正在关机。

推荐操作顺序：

1. 正常关机。
2. 等阀门、风机、压缩机等完成关机过程。
3. 确认709显示0。
4. 再进行校准。

### 1.4 负数必须按有符号数显示

所有偏移、温度、压力以及可能出现负数的连接变量，都要选择：

```text
16位有符号整数
```

如果偏移本来是`-20`，却显示为`65516`，说明MCGS把它当成了无符号数。此时不要写入，先把该连接变量的数据类型改成16位有符号整数。

### 1.5 在线成功不等于断电保存成功

画面结果码到达`5`只能说明：

1. 写命令已发出。
2. 目标偏移寄存器已经读回一致。
3. 又等待了约5秒，为控制器保存参数留出时间。

最终仍要真正切断板卡电源并重新上电验证。ST-Link复位不等于断电，不能代替断电保存验收。

## 3. 地址基准和设备连接原则

本项目使用PSC330的0基寄存器地址：

```text
495就是495
1573就是1573
2534就是2534
2654就是2654
```

不要自行加1。

如果MCGS设备窗口采用4xxxx显示方式，应完全照着工程中已经正常工作的连接变量配置。不要在同一工程中把0基地址和4xxxx地址混在一起。

本文中的变量分为两类：

1. `R`开头：设备连接变量，连接PSC330。
2. `n`开头：MCGS本地变量，只存在于触摸屏内部。

PSC316的实时值、偏移镜像和网关状态也都通过PSC330读取，所以MCGS仍然只连接PSC330，不直接切换到PSC316串口。

### 4.1 打开实时数据库

3. 先搜索下面表格中的变量。

### 4.2 新建设备连接变量的方法

以`R0495_330_NTC0偏移`为例：

1. 在实时数据库空白处单击鼠标右键。
2. 选择`新增对象`。
3. 对象名称输入`R0495_330_NTC0偏移`。
4. 对象类型选择`数值型`。
5. 打开该对象的`设备连接`属性。
6. 设备选择当前连接PSC330的Modbus设备。
7. 寄存器区与现有PSC330参数变量保持一致。
8. 地址填写`495`。
9. 数据类型选择`16位有符号整数`。
10. 读写属性选择`读写`。
11. 点击确定。

实时值只用于显示，属性选择`只读`。偏移用于校准，必须选择`读写`。

## 10. PSC330 NTC完整操作实例

下面以`NTC0回风温度`为例。

假设：

```text
标准温度 = 25.0℃
PSC330当前内部值 = 243，即24.3℃
当前偏移 = -2，即-0.2℃
```

### 10.1 校准前准备

1. 将标准温度探头与PSC330回风温度探头放在尽量相同的位置。
2. 避免一支探头靠近热源、风口或金属壁，另一支不在同样环境。
3. 等两边温度稳定。
4. 建议至少观察30至60秒，不要在数字持续跳变时校准。
5. 正常停机并确认709=0。

### 10.2 画面操作

1. 打开`PSC330校准`窗口。
2. 点击`NTC0回风温度`。
3. 点击`读取当前值并备份原偏移`。
4. 确认：

```text
n330CalCurrent = 243
n330CalOldOffset = -2
n330CalBackupValid = 1
n330CalResult = 1
```

5. 在`标准工程值`输入框输入`25.0`。
6. 点击`计算新偏移`。
7. 应看到：

```text
n330CalStandardRaw = 250
n330CalExpectedOffset = 5
n330CalResult = 2
```

8. 人工复算：

```text
-2 + 250 - 243 = 5
```

9. 复算一致后点击`确认写入`。
10. 观察结果码：

```text
3 = 已发起写入
4 = 偏移已经读回一致
5 = 又等待约5秒，可以准备断电保存验证
```

11. 观察回风温度，应从约24.3℃变化到约25.0℃。
12. 再与标准温度计比较。

### 10.3 判定

在线校准通过至少需要：

- 结果码到达5。
- 写后读回等于5。
- 当前工程值接近25.0℃。
- 其他NTC通道偏移没有变化。

断电保存通过还需要完成第16章。

下面以`AI1回风湿度`为例。

假设：

```text

PSC330当前内部值 = 486，即48.6%RH
当前偏移 = 3，即+0.3%RH
```

### 11.1 校准前检查

1. 确认AI1实际接入的是湿度变送器。
2. 确认变送器是0至10V还是4至20mA。
3. 检查参数460和参数432与接线一致。
4. 错误类型必须先修正，不能先校准偏移。
5. 将标准湿度计与回风湿度探头放在相同环境。
6. 等湿度稳定。
7. 确认709=0。

### 11.2 画面操作

1. 点击`AI1回风湿度`。
2. 点击`读取当前值并备份原偏移`。
3. 在标准值输入框输入`50.0`。
4. 点击`计算新偏移`。
5. 预期：

```text
标准内部值 = 500
新偏移 = 3 + 500 - 486 = 17
```

6. 确认画面新偏移为17。
7. 点击`确认写入`。
8. 等结果码到达5。
9. 回风湿度应接近50.0%RH。

### 11.3 AI其他通道标准值输入规则

| 通道 | 标准输入示例 | 脚本换算 |
|---|---|---|
| AI0房间压差 | 输入`120` | 不乘10 |
| AI1回风湿度 | 输入`50.0` | 自动乘10 |
| AI2 CO2 | 输入`800` | 不乘10 |
| AI3送风压力 | 输入`350` | 不乘10 |
| AI3送风风速 | 输入`4.5` | 自动乘10 |
| AI4新风湿度 | 输入`65.0` | 自动乘10 |

输入单位必须与当前值寄存器的工程单位一致。对压力通道如果现场显示单位不是本文示例，先核对当前工程的量程和显示单位，不要自行把kPa、Pa、MPa混用。

### 11.4 AI三点验证

偏移写入后不要只验证一个点。使用标准信号源或标准环境至少检查：

1. 量程低点。
2. 量程中点。
3. 量程高点。

若三个点误差基本相同，偏移修正有效。

若中点准确但低点、高点误差方向相反或越来越大，属于量程或斜率问题，不能继续加偏移。

## 12. PSC316压力AI完整操作实例

下面以`1号外机高压1`为例。

假设：

```text
标准压力 = 1500

当前偏移 = -5
```

### 12.1 校准前准备

1. 确认实际校准的是1号PSC316。
2. 确认标准压力设备接在压缩机1高压通道。
3. 确认1号外机在线状态为1。
4. 确认网关写状态不是1。
5. 确认PSC330的709=0。
6. 压力稳定后再读取。

### 12.2 画面操作

1. 打开`PSC316校准`。
2. 点击`1号外机`。

4. 点击`高压1`。

7. 在标准值输入框输入`1500`。
8. 点击`计算新偏移`。

```text
新偏移 = -5 + 1500 - 1490 = 5
```

10. 确认新偏移显示5。
11. 点击`确认写入`。
12. 观察网关状态应出现：

```text
1 = 正在写
```

### 12.3 必须防止写错通道

1号外机实时值地址是：

```text
1573 高压1
1574 低压1
1575 高压2
1576 低压2
```

但偏移地址是：

```text
2654 高压1
2655 高压2
2656 低压1
2657 低压2
```

因此高压2的当前值是1575，偏移却是2655。低压1的当前值是1574，偏移却是2656。配套脚本已按这个对应关系编写，不要自行改成同序映射。

## 15. 常见问题排查

### 15.1 点击按钮没有任何变化

依次检查：

1. 脚本是否粘贴在`抬起脚本`。
2. 按钮是否被透明控件覆盖。
3. 本地变量名称是否与脚本完全一致。
4. 脚本检查是否通过。
5. 是否运行了修改后的工程，而不是旧工程。

### 15.2 能计算但写不进去

检查：

1. 709是否等于0。
2. 偏移连接变量是否为`读写`。
3. 变量是否连到正确地址。
4. 是否还有旧策略不断把偏移写回旧值。
5. PSC316是否在线。
6. PSC316网关状态是否为1。
7. 网关错误码是什么。

### 15.3 PSC316直接显示成功，没有看到状态1

监视脚本要求先观察到本次状态1，再接受状态2。这样可以防止把上一次残留的状态2误认为本次成功。

如果一直看不到状态1：

1. 检查偏移连接变量是否真正写入PSC330。
2. 检查200ms策略是否运行。
3. 检查所选外机是否正确。
4. 检查网关状态变量地址。
5. 检查是否有其他MCGS脚本或监控软件同时写同一参数。

### 15.4 负数显示成655xx

将对应设备连接变量改为16位有符号整数。

常见换算：

```text
65535 = -1
65516 = -20
65036 = -500
```

不要把65516当作正数写回。

### 15.5 写完当前值没有变化

检查：

1. 当前值是否为有效传感器数据。
2. 标准值和当前值是否使用同一工程单位。
3. 选中的是否是正确通道。
4. AI3是否按实际压力/风速用途选择。
5. PSC316是否选中了正确外机。
6. 读回偏移是否等于预计偏移。

### 15.6 写入一台PSC316，另一台也变化

立即停止继续校准，执行：

1. 记录四台外机对应偏移。
2. 只选择其中一台写一个小的测试偏移。
3. 检查其他三台偏移是否保持。
4. 检查四台PSC316的内机通讯站号是否分别为1、2、3、4。
5. 检查页面是否在切换外机后重新读取并备份。
6. 检查是否存在广播写入或旧脚本。

### 15.7 读回成功但断电后丢失

这说明在线通信成功，但EEPROM保存没有通过。

不能把该项标记为最终通过。应：

1. 确认结果码已经到5。
2. 再多等待几秒。
3. 真正断电。
4. 重新上电读取。
5. 若仍丢失，按固件存储问题记录，不要反复修改MCGS偏移。

### 15.8 校准后相邻压力值跳动1个单位

压力传感器本身和ADC可能存在正常采样波动。判断时：

1. 连续记录至少10至30秒。
2. 比较平均值，不只看单个瞬时值。
3. 同时确认相邻通道的偏移寄存器没有被改写。
4. 如果只是工程值在32和33之间跳，而偏移地址保持不变，先按采样波动记录。
5. 如果相邻偏移也发生变化，则属于串位，不通过。

## 16. 真正断电保存验收

### 16.1 PSC330验收

至少选择：

- AI0偏移499。
- AI3偏移496。
- AI4偏移457。
- NTC0偏移495。
- NTC11偏移484。

执行：

1. 记录所有原偏移。
2. 分别测试一个正值和一个负值。
3. 等结果码到5。
4. 再等待至少5秒。
5. 切断PSC330供电。
6. 等待电源完全放电。
7. 重新上电。
8. 读回全部目标偏移。
9. 检查是否丢失、串位或恢复默认。
10. 重复真正断电共3次。

三次均保持才可标记断电保存通过。

### 16.2 PSC316验收

每台PSC316分别写不同的小测试值，例如：

| 外机 | NTC0测试偏移示例 |
|---:|---:|
| 1号 | 11 |
| 2号 | 22 |
| 3号 | 33 |
| 4号 | 44 |

示例仅用于隔离测试，正式测试前要确认这些值不会造成传感器保护误判。

执行：

1. 记录四台板原偏移。
2. 逐台选择外机。
3. 每次重新读取并备份。
4. 写入不同值。
5. 每台都等网关状态1到2、结果码到5。
6. 重新读四台，确认互不串台。
7. 真正切断四台PSC316供电。
8. 重新上电。
9. 读回四个不同值。
10. 重复真正断电共3次。

只连接两台板时，只能判定两台独立性，不能把“四台独立保存”标记为通过。

## 17. 边界和安全验收

### 17.1 偏移范围

| 类型 | 最小值 | 最大值 |
|---|---:|---:|
| PSC330 AI | -5000 | 5000 |
| PSC330 NTC | -500 | 500 |
| PSC316压力AI | -5000 | 5000 |
| PSC316 NTC | -500 | 500 |

### 17.2 每类必须测试

1. 正偏移。
2. 负偏移。
3. 零偏移。
4. 最小允许值。
5. 最大允许值。
6. 小于最小值，必须拒绝。
7. 大于最大值，必须拒绝。
8. 相邻通道偏移不得变化。
9. 切换通道后，旧计算结果不得写到新通道。
10. 切换PSC316外机后，旧外机计算结果不得写到新外机。

边界测试结束后必须恢复全部原始偏移。

## 18. 推荐的正式校准流程

每个通道都按下面顺序执行，不要跳步：

1. 确认标准仪器有效。
2. 确认传感器接线、类型和量程。
3. 正常停机并等待709=0。
4. 选择控制器：PSC330或目标PSC316。
5. 选择通道。
6. 点击读取并备份。
7. 把原偏移抄到校准记录表。
8. 等待当前值稳定。
9. 输入标准工程值。
10. 点击计算新偏移。
11. 人工按公式复算。
12. 检查新偏移没有超范围。
13. 点击确认写入。
14. 等结果码到5。
15. 检查当前工程值是否接近标准值。
16. 检查相邻通道和其他外机没有变化。
17. 做低、中、高点复核。
18. 完成全部通道后做三次真正断电。
19. 断电后再次复核标准点。
20. 保存校准记录。
