# MCGSPro每天单时段定时完整实施说明

适用对象：第一次使用MCGSPro脚本的操作人员。

适用控制器：PSC330。

生成日期：2026年9月8日。

## 1. 这套定时功能是什么

这套方案不再区分周一、周二到周日，也不再建立14个时段。

画面上只保留一个每天重复的时间段：

- 每天开始时间。
- 每天结束时间。
- 启用每天定时。
- 停止定时并关机。

设置一次以后，星期一至星期日每天都按同一个时间段运行。

默认时间为：

```text
开始：00:00
结束：00:00
```

这个默认设置表示尚未设置有效运行时段，计算目标为0，不会自动开机。

如果设置为`08:00至18:00`：

1. 每天08:00开始要求开机。
2. 到每天18:00立即把运行目标改为0。
3. PSC330收到目标0后开始执行正常关机顺序。

如果设置为`22:00至06:00`，脚本自动按跨午夜处理：

1. 每天22:00开始要求开机。
2. 跨过午夜后继续运行。
3. 到次日06:00立即把运行目标改为0。
4. PSC330收到目标0后开始执行正常关机顺序。

开始时间与结束时间完全相同时，脚本按无有效时段处理，计算目标为0。这样刚创建变量或恢复默认值时，不会意外全天开机。

## 2. PSC330真正使用的四个寄存器

| 地址 | MCGS变量名 | 读写 | 作用 |
|---:|---|---|---|
| 165 | `R0165_定时模式使能` | 读写 | 0普通控制，1定时控制 |
| 709 | `R0709_开关机步骤` | 只读 | 0完全停机，1启动，2运行，3/4/5关机过程 |
| 714 | `R0714_当前控制方式` | 只读 | 0本地，1远程，2 PLC，3定时 |
| 1388 | `R1388_定时运行目标` | 读写 | 0要求关机，1要求开机 |

定时功能的正确关系是：

1. MCGS把165写成1，PSC330进入定时控制。
2. MCGS根据触摸屏时间计算当前目标。
3. 在运行时段内，MCGS把1388写成1。
4. 在运行时段外，MCGS把1388写成0。
5. PSC330收到1388后，仍由固件执行正常的阀门、风机、压缩机、加热和加湿启停顺序。

脚本绝对不能直接写Y点，也不能直接开风机或压缩机。

7. 是否仍受最小停机时间限制。

只看到`nDailyScheduleTarget=1`不能证明PSC330已经收到开机命令。必须同时看到`R1388_定时运行目标=1`。

## 11. 第九步：测试停止定时并关机

在机组处于定时运行时，按`停止定时并关机`。

应观察到：

2. `R1388_定时运行目标`变成0。

## 12. 结果码说明

| 结果码 | 含义 | 处理 |
|---:|---|---|
| 0 | 定时未启用 | 正常停用状态 |
| 1 | 已请求启用 | 等待设备读回 |
| 2 | 定时运行正常 | 165=1、714=3、1388与计算目标一致 |
| 3 | 正在写运行目标 | 等待下一次设备读回 |
| 4 | 尚未确认进入定时 | 检查165、714及通信 |
| 5 | 正在正常关机 | 等待709回到0 |
| 6 | 已关机并退出定时 | 正常完成 |
| 7 | 已恢复默认00:00至00:00 | 当前无有效运行时段 |
| 101 | 时间设置越界 | 检查小时0至23、分钟0至59 |
| 102 | 触摸屏时钟异常 | 校准触摸屏系统时间 |

## 13. 常见问题

### 13.1 显示“定时”，计算目标也是1，但机器不启动

先确认以下4个实时值：

```text
165 = 1
714 = 3
1388 = 1
709 = 0、1或2中的哪一个
```

如果前三项正确，说明定时脚本已经完成工作。机器不启动通常是PSC330正在执行启动等待、存在故障、外部连锁不允许，或压缩机最小停机时间未到。

### 13.2 当前时间不变化

`strDailyScheduleNow`不变化，说明1秒循环策略没有运行。

检查：

1. 策略是否为循环策略。
2. 策略是否启用。
3. 周期是否为1000ms。
4. 脚本是否粘贴到了正确策略中。

### 13.3 每隔1秒反复写寄存器

正常脚本只有设备读回与目标不一致时才写1388。

如果通信日志仍显示每秒写：

1. 检查是否还运行着旧周定时策略。
2. 检查其他按钮或策略是否也在写165、1388。
3. 旧周定时策略必须停用，不能与新策略同时运行。

### 13.4 00:00至23:59会不会午夜停一下

不会。

当前脚本采用“开始时间包含、结束时间不包含”的方式。设置`00:00至23:59`时，会在23:59发出关机目标，不是严格的24小时连续运行。

若确实需要全天不间断运行，应另设“全天运行”开关，不能用分钟级的开始/结束时间同时表达23:59之后的最后一分钟。

### 13.5 想每天晚上运行到第二天早晨

直接把开始时间设置得大于结束时间，例如：

```text
开始 = 22:00
结束 = 06:00
```

脚本会自动识别为跨午夜时段。

### 13.6 开始和结束都为00:00是什么意思

表示无有效运行时段，当前计算目标为0。这是本方案的安全默认值，不表示全天运行。

若需要全天运行，设置为：

```text
开始 = 00:00
结束 = 23:59
```

### 13.7 改了开始或结束时间，需要再次按启用吗

定时已经启用时不需要。循环策略每秒读取最新设置，新时间在下一秒生效。

为了避免误操作，正式画面可在时间输入区增加管理员权限。

### 13.8 退出定时后由谁控制

当165回到0后，PSC330重新按普通控制来源执行。普通控制来源可能是本地、远程开关或PLC。

本方案的`停止定时并关机`会先确保机组完整关机，再退出定时，避免退出瞬间产生控制来源切换。
